# 📊 TailorTrack-Analytics — Interactive Data Visualization Dashboard

**TailorTrack-Analytics** is an interactive data visualization and analytics dashboard designed and prototyped with **Google AI Studio**. It allows users to upload structured datasets (such as CSV files) and dynamically explore metrics across multiple visual perspectives.

## ✨ Key Features
* **Multi-View Visualizations:** Explore the same dataset through time-series line charts, category bar charts, distribution breakdowns, and scatter plots.
* **Dynamic KPI Cards:** Automatically summarizes key performance indicators including total revenue, net profit, unit volume, and customer satisfaction.
* **Interactive Filtering:** Slice and filter data in real time by date range, region, product category, sales channel, and order status.
* **Custom Dataset Support:** Built to adapt accurately to user-provided tabular data.

## 🛠️ Built With
* **Google AI Studio** (Prototyping & Prompt Engineering)
* **Gemini API** (Data structuring and automated visualization setup)

## 🚀 How It Works
1. **Load Your Data:** Upload or connect a structured dataset (e.g., `datos_prueba_dashboard.csv`).
2. **Explore Views:** Switch between different chart types and analytical perspectives.
3. **Filter & Analyze:** Apply regional, temporal, or categorical filters to uncover trends and outliers.
